1. Hiểu về giao thức (Transport)
Transport là "con đường" mà client và server dùng để giao tiếp. MCP định nghĩa hai loại chính:

STDIO (Standard Input/Output): Dành cho kết nối cục bộ. Client (như Claude Desktop) sẽ tự khởi chạy MCP server như một tiến trình con (subprocess) và giao tiếp qua luồng stdin/stdout. Ưu điểm là độ trễ cực thấp, không cần cấu hình mạng, và bảo mật cao vì không lộ ra ngoài .

Streamable HTTP: Dành cho kết nối từ xa. Server chạy độc lập và lắng nghe trên một endpoint HTTP (ví dụ: http://localhost:8000/mcp). Client gửi yêu cầu qua HTTP POST và có thể nhận phản hồi dạng JSON hoặc luồng sự kiện (SSE) . Đây là giao thức hiện đại, thay thế cho SSE cũ, hỗ trợ quản lý phiên và khả năng phục hồi kết nối .

Tóm lại: stdio cho các công cụ chạy ngay trên máy bạn, HTTP cho các server ở xa hoặc khi bạn muốn chạy nó như một dịch vụ độc lập.

2. Cách sử dụng MCP với Claude CLI
Claude Code CLI (công cụ dòng lệnh) hỗ trợ cả hai loại transport, cho phép bạn kết nối linh hoạt .

Cú pháp cơ bản:

bash
claude mcp add [tên-server] -- [lệnh-khởi-chạy]  # Cho STDIO
claude mcp add --transport http [tên-server] [URL] # Cho
Ví dụ cụ thể:

Kết nối server cục bộ (STDIO):

bash
claude mcp add my-local-tool -- npx -y @modelcontextprotocol/server-filesystem
Kết nối server HTTP (như ví dụ của bạn):

bash
claude mcp add --transport http demo-server http://localhost:8000/mcp
Lệnh này sẽ lưu cấu hình vào file .claude.json của dự án hiện tại .

Quản lý và sử dụng:

Sau khi thêm, gõ /mcp trong phiên làm việc của Claude Code để xem trạng thái và xác thực (nếu cần) .

Claude sẽ tự động nhận diện các tool từ server và gọi chúng khi bạn yêu cầu bằng ngôn ngữ tự nhiên.1. Hiểu về giao thức (Transport)
