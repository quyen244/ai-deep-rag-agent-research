Thư viện cho Supervisor Pattern:

langgraph-supervisor - Gói chuyên dụng giúp triển khai nhanh chóng mô hình Supervisor với các agent con .

langgraph-prebuilt - Chứa các thành phần agent được xây dựng sẵn như create_react_agent, rất hữu ích khi tạo các agent chuyên gia .

bash
pip install -U langgraph-supervisor
LLM & Integrations (Tùy chọn theo nhu cầu):

langchain-openai - Nếu bạn dùng các model của OpenAI.

python-dotenv - Để quản lý biến môi trường và API keys (ví dụ: OPENAI_API_KEY).

bash
pip install langchain-openai python-dotenv
